# gceTools – set de iconos

| Carpeta | Contenido |
|---|---|
| `svg/` | Vectores maestros: `logo` (con texto), `icon` (app), `icon-small` (simplificado para ≤32 px), `symbol` (transparente), `maskable` (Android/PWA/iOS), `horizontal-dark` / `horizontal-light` (cabecera web). Texto convertido a trazos (Montserrat 700/400, OFL). |
| `png/` | Exportaciones genéricas 16–1024 px y logos. |
| `web/` | favicon.ico (16/32/48), favicon.svg, apple-touch-icon, android-chrome 192/512, maskable 192/512, og-image 1200×630, `site.webmanifest`, `head-snippet.html`. |
| `windows/` | `gcetools.ico` (16–256). |
| `macos/` | `gcetools.icns`. |
| `linux/` | PNG 16–512 + SVG (hicolor). |
| `android/` | `mipmap-*/ic_launcher.png` + `play-store-512.png`. |
| `ios/` | AppIcon en todos los tamaños (sin transparencia; iOS aplica la máscara). |

Paleta: fondo `#1E2230` · rojo `#EA4335` · amarillo `#FBBC04` · verde `#34A853` · azul `#4A86E8` / `#2B6CB8` · texto `#ECEEF2` / `#BCD6EE`.
